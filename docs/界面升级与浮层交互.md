# 界面升级与浮层交互

本次按已批准的浮层审查实施。随后用户明确授权重新设计视觉，因此升级了工作空间导航、层级、色彩、表单、按钮与反馈，而非仅修补旧样式。

## 可见变化

- 统一侧栏、面包屑、轻量背景、卡片和表单，窄屏切换为紧凑导航。
- 实例、Hook、员工、SPEC、需求下发、知识库文档、页面清单与模板节点使用侧边抽屉。适用的编辑会预览到后方页面，保存前不写入数据库。
- 任务详情、目录不一致决策、员工删除、Hook 删除和流程取消保留聚焦对话框。
- 无占用实例、单独工作、非共享材料和模板删除使用锚定确认；共享材料、整站页面或正在使用的对象改用对话框。
- E2E 创建和 Wiki 阅读使用完整页面。Wiki 页面及原始证据的链接包含工作、页面和固定版本，刷新后可继续阅读。
- 所有原生 title 提示迁移为统一悬停、键盘聚焦和触摸提示；完整 SPEC 改为点击阅读。没有添加不适用的鼠标跟随提示或交互菜单。
- 统一通知、焦点恢复、Escape、未保存关闭/导航/刷新保护。Markdown 取消编辑会恢复原文，嵌套编辑不会清除父级草稿；成功提交人工答复后才清除草稿。

## 验证与预览

浏览器测试使用独立 API 桩，不触发真实飞书、模型或删除操作。桌面、触摸、键盘、抽屉、确认、草稿和版本链接对编译后的生产前端执行验证，并重复运行每个场景。截图位于本机 `target/ui-screenshots/`，内容是测试数据。

运行示例（OrbStack）：

```sh
docker run --rm --ipc=host --network feishu-claude_default \
  -v "$PWD:/workspace" -w /workspace/frontend \
  -e UI_BASE_URL=http://feishu-ui-preview:5173 \
  mcr.microsoft.com/playwright:v1.64.1-noble npx playwright test --repeat-each=2
```

先用 Node 容器构建前端，再以 `feishu-ui-preview` 名称运行 Vite preview，挂载同一个项目；测试使用已编译文件，避免热更新干扰。部署通过现有 compose 构建前后端；在线 smoke 验证 Nginx 和真实 API。详细组件约定见 `.trellis/spec/frontend/floating-ui.md`。
