# 液态玻璃材质

本次只调整表面材质，保留原有业务卡片、字体、间距、圆角、图标、动效、文案和操作流程。新增的「外观」入口复用现有 Surface 对话框，提供跟随系统／浅色／深色主题和各自独立的玻璃浓度（0–1.5，默认 1），设置立即生效并保存在当前浏览器。

当前产品没有壁纸、视频背景、图片背景卡片、播放器或连续图表区域，因此没有给普通卡片强加灰色透明层，也没有新增这些内容。测试中的图片背景是验证夹具，不会出现在产品里。现有浮层背后是 DOM，不能用 Canvas 直接读取其像素；默认使用主题 ink 与保守浓度。这样的回退可能接近不透明，以保证默认可读性。

## 实现

- `ProductUI.css` 保持原有设计基础，新增共享 `GlassMaterial.css` 提供已注册的材质颜色、数值和明暗主题令牌。背景、滤镜、边缘阴影和文字颜色统一配置，不逐个业务组件写配方。
- `glass/scene.js` 读取图片背景／图片元素，按 5×3 取样、剔除两端各两点，计算亮度、纹理与色度。图片变化、主题、尺寸、滚动、布局变化后重新评估。不读取或上传页面截图。
- `glass/material.js` 负责行共享的明暗判断、0.45/0.55 滞回、浓度和饱和度，以及基于样本的对比度保护。浅色次级 ink 固定为 RGB 58/58/64、透明度 .70：参考值 60/60/67 在纯白背景上略低于 4.5:1，故只做固定颜色校准，不随背景改变文字透明度。对比度不足时提高 tint 密度；参考浓度区间不是无条件上限。
- 独立文字叶节点使用 multiply／plus-lighter，不对包含按钮、表单和错误提示的整块内容混合。直接文本节点保留正常合成，以保持原有 DOM；对比度计算同时按更保守的正常合成校验。
- `glass/lens.js` 用八块缓存图加中性中心构成九宫格位移图；仅边缘弯曲，中心不弯曲。每个表面有独立 SVG/filter ID；图片 decode 后才挂载滤镜。普通尺寸变化只移动或伸缩图块，圆角／rim 改变才重新取对应缓存。
- 凸 superellipse 使用 CSS 的 2^K 指数，匹配实际圆角；混合圆角、椭圆、凹形或过小图块等不支持的情况保留 CSS 材质。RGB 三通道分别弯曲后 screen 合成；大 rim 相对小圆角时降低色散。
- Chromium 同时通过浏览器和 CSS 支持检查才启用 URL 镜头。Firefox、Safari、动画、will-change、变换等场景回退 CSS；减弱透明度和强制颜色模式回退实心表面。

这里提供的是 15 个样本及不可读取背景的保守回退保护，不声称能测量所有屏幕像素。默认浓度验证可读性；用户主动调到 0 时，实际效果仍取决于背景。
